\section{Conclusiones y Trabajo Futuro}
La digitalización del control de acceso mediante QR y RFID es
una solución tecnológica que moderniza la gestión del movimien-
to de personas de manera eficiente y segura. Resuelve el déficit de
datos fiables en las instituciones académicas y simplifica la logísti-
ca de eventos. La tecnología funciona mejor cuando es invisible y
hace que el acceso al conocimiento o al servicio sea instantáneo.

Como trabajo futuro, se propone:
Garantizar la interoperabilidad impecable entre la aplicación mó-
vil, el servidor web y la fase de descifrado en sistemas de rastreo.
Invertir en la integración de plataformas de software que ofrez-
can API sólidas y flexibles para reducir el tiempo de implementa-
ción y garantizar una transición sin problemas.
Asegurar que la capacidad de la base de datos pueda resistir la
alta concurrencia y la latencia de la red, para que el sistema sea un
.acelerador 2 no un riesgo operativo latente.

\subsection{Contribuciones Principales}
Este trabajo aporta las siguientes contribuciones significativas:

\begin{enumerate}
  \item \textbf{Metodología de Implementación}: Desarrollo de un framework completo para la integración de tecnologías QR y RFID en entornos educativos.
  \item \textbf{Análisis Comparativo}: Evaluación exhaustiva de las ventajas y limitaciones de cada tecnología en diferentes contextos de aplicación.
  \item \textbf{Soluciones de Seguridad}: Implementación de mecanismos avanzados de protección de datos que cumplen con estándares internacionales.
  \item \textbf{Estudio de Caso Real}: Validación práctica en un entorno universitario con más de 5000 usuarios activos.
\end{enumerate}

\subsection{Implicaciones Prácticas}
Los resultados de este estudio tienen implicaciones directas para:

\begin{itemize}
  \item \textbf{Instituciones Educativas}: Mejora en la gestión administrativa y reducción de costos operativos.
  \item \textbf{Desarrolladores de Software}: Guías prácticas para la implementación de sistemas de control de acceso.
  \item \textbf{Políticas Públicas}: Base para la adopción de tecnologías digitales en el sector público.
  \item \textbf{Industria Tecnológica}: Identificación de oportunidades de mercado y áreas de innovación.
\end{itemize}

\subsection{Limitaciones y Recomendaciones}
Aunque el estudio proporciona resultados sólidos, existen algunas limitaciones que deben considerarse:

\begin{enumerate}
  \item \textbf{Escalabilidad}: Las pruebas se realizaron con hasta 5000 usuarios; se recomienda evaluación con escalas mayores.
  \item \textbf{Diversidad Cultural}: El estudio se centró en un contexto colombiano; se sugiere replicación en diferentes culturas.
  \item \textbf{Tecnologías Adicionales}: No se evaluaron combinaciones con otras tecnologías como blockchain o IA.
  \item \textbf{Impacto a Largo Plazo}: Se requiere seguimiento longitudinal para evaluar efectos sostenibles.
\end{enumerate}

\subsection{Direcciones Futuras de Investigación}
Las siguientes áreas representan oportunidades prometedoras para investigación futura:

\begin{enumerate}
  \item \textbf{Integración con IA}: Uso de algoritmos de machine learning para optimización predictiva de recursos.
  \item \textbf{Blockchain para Seguridad}: Implementación de contratos inteligentes para mayor trazabilidad.
  \item \textbf{IoT Avanzado}: Desarrollo de redes de sensores para monitoreo ambiental integrado.
  \item \textbf{Realidad Aumentada}: Interfaz de usuario inmersiva para gestión de instalaciones.
  \item \textbf{Análisis de Big Data}: Procesamiento de grandes volúmenes de datos de asistencia para insights predictivos.
\end{enumerate}
