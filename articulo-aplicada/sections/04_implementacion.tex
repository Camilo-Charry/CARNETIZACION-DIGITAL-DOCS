\section{Implementación del Software}

La implementación exige la integración de varios componentes tecnológicos para garantizar la funcionalidad y la seguridad.

\section{Plataformas y Componentes Clave}
\textbf{Desarrollo de Aplicaciones:} Las soluciones se construyen comúnmente en la plataforma Android Studio utilizando lenguajes como JAVA y bases de datos como Firebase [4, 3.1].

\textbf{Infraestructura de Datos:} Se utilizan bases de datos locales como SQLite para la robustez del sistema y bases de datos remotas que alimentan un sistema de administración para el control del sistema [3.1, 1.2].

\textbf{Integración de Hardware:} En sistemas RFID, el lector se conecta al dispositivo móvil para leer el tag de las tarjetas plásticas [3.1]. Es posible reemplazar lectores RFID con lectores de códigos QR en la infraestructura existente [4.4].

\section{Mecanismos de Operación y Seguridad}
\textbf{Funcionamiento Operativo:} Al mostrar el código QR, un lector lo escanea, confirma la identidad y anota la hora. El sistema RFID registra automáticamente la información de asistencia cuando un empleado se acerca al lector [2.3].

\textbf{Protección de Datos:} Para proteger los datos sensibles de ubicación y presencia, el sistema emplea el método de cifrado AES (Advanced Encryption Standard) [5]. Implementar medidas como el cifrado de datos y una autenticación sólida es esencial para proteger la información y cumplir con regulaciones de privacidad como GDPR [2.1].

\textbf{Seguridad Mejorada:} Los códigos QR personalizados son difíciles de falsificar [2.2]. El uso de RFID permite prevenir los robos y restringir automáticamente zonas peligrosas a empleados no capacitados [1.5, 2.4].
